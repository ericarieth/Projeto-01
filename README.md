
# Projeto-01 - Strategy Pattern
 
## Descrição
 
Projeto desenvolvido em Java para demonstrar a aplicação do padrão de projeto Strategy (GoF).
 
## Objetivo
 
Simular um sistema de envio de notificações utilizando diferentes estratégias:
 
- E-mail
- SMS
- WhatsApp
 
## Conceitos Aplicados
 
- Orientação a Objetos
- Interfaces
- Polimorfismo
- SOLID
- Strategy Pattern
 
## Estrutura do Projeto
 
NotificacaoStrategy
├── EmailNotificacao
├── SmsNotificacao
└── WhatsAppNotificacao
